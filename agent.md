# agent.md

## Purpose

This repository builds a static web app for recording four-player mahjong scores and calculating final settlements.

## Working Rules

- Keep the app fully static so it can be hosted on GitHub Pages.
- Treat URL encoding and browser-side cache as the persistence layer.
- Follow Mahjong Soul style score settlement rules where specified in `spec.md`.
- Keep calculations deterministic and easy to test.
