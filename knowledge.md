# knowledge.md

## Confirmed Facts

- Hosting target is GitHub Pages.
- The app should remain fully static.
- Session persistence should rely on browser cache and URL encoding.
- Initial score input assumes 25000-point starting scores.
- Return point target is 30000.
- Score calculation should aim to match Mahjong Soul behavior.
- The current MVP exposes configurable placement bonuses with defaults of `+10 / +5 / -5 / -10`.
- The current MVP applies tie-breaking by input order.
- The current MVP applies oka only to first place.

## Open Points

- Exact default placement bonus table is not yet finalized.
- Exact Mahjong Soul rounding behavior still needs verification.
- URL payload format is not yet fixed.
